关于动效

  • 全部动效由本地 assets/gsap.min.js 驱动，离线可看
  • 每一处动画都有明确动机：入场编排表达层级、数字滚动表达状态、逐字流演示流式回答、翻卡预演复习交互
  • 全部尊重系统「减弱动态效果」设置，开启后自动退化为静态

落地方式（选定后执行）

  • 色板 / 圆角 / 字体 / 动效曲线提炼为 Tailwind 主题 tokens，组件基于 shadcn/ui 定制
  • 设计稿中的 GSAP 动效会封装成 React 组件（入场编排、翻卡、流式文字、图表生长）
  • 三套方案只是方向差异，功能范围完全一致，不影响 PLAN.md 里的里程碑
